# Sato Clinic Demo Site

This repository contains a fictional medical website created for web-design / learning purposes.

- It is **not** an actual medical institution.
- It does **not** accept appointments, phone calls, email inquiries, or personal information.
- Names, addresses, staff profiles and medical information shown on the page are sample content.
- The page includes visible DEMO labeling and `noindex, nofollow` metadata.

For GitHub Pages, publish the repository root containing `index.html`.
